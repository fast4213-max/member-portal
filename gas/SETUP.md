# GAS のセットアップ手順

台帳のデータ置き場（Googleスプレッドシート）と、画面から呼ばれるプログラム（GAS）を用意する手順です。
**パソコンで**作業してください（スマホだと Apps Script の画面が使いにくいです）。所要時間は30分くらいです。

> パスワードやトークンは、この手順の中で**スプレッドシートのメニューから入力**します。
> コードやGitHubには書かないでください。

---

## 手順1　スプレッドシートを作る

1. [Googleドライブ](https://drive.google.com/) を開く
2. 左上の［＋ 新規］→［Googleスプレッドシート］
3. 左上の「無題のスプレッドシート」をクリックして、名前を **組合員台帳** にする
4. **共有はしない**でください（右上の［共有］は「制限付き」のまま）

## 手順2　プログラム（GAS）を貼り付ける

1. スプレッドシートの上のメニュー［拡張機能］→［Apps Script］
   → 新しいタブでプログラムの編集画面が開きます
2. 左上の「無題のプロジェクト」をクリックして、名前を **組合員台帳アプリ** にする
3. 最初からある `コード.gs` を開き、中身を全部消して、GitHub の [`gas/Code.gs`](Code.gs) の中身を貼り付ける
   - GitHub でファイルを開き、右上の **「Copy raw file」**（四角が2つ重なったアイコン）を押すと全部コピーされます
4. 左の「ファイル」の横の［＋］→［スクリプト］で新しいファイルを作り、下の表の名前を付けて、同じように中身を貼り付ける。これを全部のファイルでくり返す

   | 作るファイル名（.gs は自動で付く） | 貼り付けるファイル |
   |---|---|
   | schema | [`gas/schema.gs`](schema.gs) |
   | db | [`gas/db.gs`](db.gs) |
   | auth | [`gas/auth.gs`](auth.gs) |
   | audit | [`gas/audit.gs`](audit.gs) |
   | members | [`gas/members.gs`](members.gs) |
   | requests | [`gas/requests.gs`](requests.gs) |
   | trash | [`gas/trash.gs`](trash.gs) |
   | backup | [`gas/backup.gs`](backup.gs) |
   | line | [`gas/line.gs`](line.gs) |
   | setup | [`gas/setup.gs`](setup.gs) |
   | test | [`gas/test.gs`](test.gs) |

   ※ ファイルの並び順は関係ありません。名前は違っても動きますが、同じにしておくと後で分かりやすいです

5. 設定ファイル（appsscript.json）を入れる
   1. 左の ⚙（プロジェクトの設定）を開く
   2. 「**「appsscript.json」マニフェスト ファイルをエディタで表示する**」にチェック
   3. 左の ＜ ＞（エディタ）に戻ると `appsscript.json` が増えているので、中身を全部消して [`gas/appsscript.json`](appsscript.json) を貼り付ける
6. 上の 💾（保存）を押す（または Ctrl+S）

## 手順3　初期設定（シートを作る）

1. **スプレッドシートのタブに戻って、ページを再読み込み**（F5）
2. 数秒待つと、上のメニューに **［台帳アプリ］** が出てきます
3. ［台帳アプリ］→［① 初期設定（シートを作る）］
4. 初回だけ「承認が必要です」と出るので、許可します
   1. ［続行］→ 自分のアカウントを選ぶ
   2. 「**このアプリは Google で確認されていません**」と出たら、左下の［詳細］→［組合員台帳アプリ（安全ではないページ）に移動］
      - 自分で作ったプログラムなので、この表示が出るのは正常です
   3. ［許可］
5. 許可のあと、もう一度 ［台帳アプリ］→［① 初期設定］ を押す
6. 「初期設定が終わりました」と出ればOK。下のタブにシートが5つできています

   | シート | 中身 |
   |---|---|
   | members | 台帳（1人1行） |
   | family | 家族（1人1行） |
   | change_requests | 組合員からの申請 |
   | members_history | 変更履歴（承認・削除などの前の内容） |
   | audit_log | 行動ログ（誰がいつ何をしたか。値は書かない） |

   マイドライブには、バックアップ用のフォルダ「組合員台帳_バックアップ」ができます

> ⚠ シートの1行目（見出し）は変えない・列を並べ替えない・シート名を変えないでください。プログラムが読めなくなります。
> データを直接書き換えるのも避けてください（変更は画面から申請→承認で行います）。

## 手順4　パスワードを決める

1. ［台帳アプリ］→［② 共通パスワードを設定］
   - 組合員みんなに伝えるパスワードです。8文字以上
   - 確認のため2回入力します
2. ［台帳アプリ］→［③ 管理パスワードを設定］
   - 役員だけが知るパスワードです。**共通パスワードとは別のもの**にしてください
3. 決めたパスワードは紙などに控えてください。保存されるのは暗号化した値だけなので、**忘れたら取り出せません**（その場合は同じメニューで設定し直せます）

## 手順5　動作テスト

1. ［台帳アプリ］→［④ 動作テスト］→［はい］
2. 1分ほどで結果が出ます。**全部 ✅** ならOK
   - 架空の人（社員番号 0000000・山田 太郎）で、申請 → 承認 → 更新 → 却下 → 取消 → 削除 → 復元 までを実際に試しています
   - 終わるとテストのデータは消えます（audit_log にはテストの記録が残りますが、正常です）
3. ❌ があったら、その画面をスクリーンショットして Claude に見せてください

## 手順6　Webアプリとして公開（デプロイ）

画面（GitHub Pages）から呼べるようにします。

1. Apps Script のタブで、右上の［デプロイ］→［新しいデプロイ］
2. 「種類の選択」の ⚙ →［ウェブアプリ］
3. 次のように設定する
   - 説明：`v1`
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. ［デプロイ］→ 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/……/exec`）をコピー
5. スプレッドシートに戻って［台帳アプリ］→［⑤ Web接続テスト］→ URL を貼り付けて OK
   → 「✅ つながりました」ならOK
6. このURLを Claude に教えてください（画面側に設定します）

> 「アクセスできるユーザー：全員」でも、パスワードがないと何もできません（確認はすべてGAS側でしています）。
> URL自体は秘密ではありませんが、むやみに広めないでください。

## 手順7　自動処理をオンにする

1. ［台帳アプリ］→［自動処理をオンにする］
   - 毎日3時ごろ：スプレッドシートを丸ごとバックアップ（30日分を保存。古いものは自動で削除）
   - 毎日12時ごろ：新しい承認待ちがあればLINEに通知（LINEを設定するまでは何もしません）
2. ［台帳アプリ］→［設定状況を確認］で、全部 ✅ になっているか確認

LINE通知の設定は、画面ができてから別の手順書で案内します。

---

## プログラムを直したとき（大事）

GitHub のコードが新しくなったら、変わったファイルを貼り直して 💾 保存したあと：

1. ［デプロイ］→［**デプロイを管理**］
2. 右上の ✏（編集）→「バージョン」を **［新バージョン］** にする →［デプロイ］

→ **URLは変わりません**。
［新しいデプロイ］を選ぶとURLが変わってしまい、画面からつながらなくなるので注意してください。

## メニュー一覧

| メニュー | すること |
|---|---|
| ① 初期設定 | シートとバックアップフォルダを作る（何度押しても大丈夫） |
| ② 共通パスワードを設定 | 組合員用。変えると、ログイン中の人は全員ログアウト |
| ③ 管理パスワードを設定 | 役員用。変えると、ログイン中の人は全員ログアウト |
| ④ 動作テスト | 架空データで一通り試す |
| ⑤ Web接続テスト | デプロイしたURLにつながるか |
| 自動処理をオンにする | 毎日のバックアップ・LINE通知 |
| 今すぐバックアップ | その場でバックアップを1つ作る |
| LINEの設定 / LINEにテスト送信 | LINE通知の設定（あとで） |
| 全員をログアウトさせる | パスワードが漏れたかも、というときに |
| 設定状況を確認 | 何が設定済みかを一覧（値は表示しない） |

## 困ったとき

| こんなとき | どうする |
|---|---|
| メニュー［台帳アプリ］が出ない | スプレッドシートを再読み込み。それでも出なければ Apps Script で 💾 保存できているか確認 |
| 「SPREADSHEET_ID が未設定です」 | ［① 初期設定］を実行 |
| Web接続テストが ❌ | デプロイの設定が「自分」「全員」になっているか。［デプロイを管理］で確認 |
| ログインで「パスワードを続けて間違えたため…」 | 5回続けて間違えると15分ロックされます。待てば解除されます |
| エラーの中身を見たい | Apps Script の左の ≡（実行数）で、エラーになった実行を開く |

## スクリプトプロパティ（参考）

メニューから設定すると、Apps Script の ⚙（プロジェクトの設定）→「スクリプト プロパティ」に保存されます。**値は誰にも見せない・どこにも貼らない**でください。

| キー | 中身 | 設定のしかた |
|---|---|---|
| SPREADSHEET_ID | 台帳のスプレッドシート | ① 初期設定で自動 |
| PASS_SALT | 暗号化用のランダム文字列（変えるとパスワードの再設定が必要） | ① 初期設定で自動 |
| BACKUP_FOLDER_ID | バックアップ先フォルダ | ① 初期設定で自動 |
| TOKEN_EPOCH | ログインの世代番号（全員ログアウトで増える） | 自動 |
| MEMBER_PASS_HASH | 共通パスワード（暗号化済み） | ② |
| ADMIN_PASS_HASH | 管理パスワード（暗号化済み） | ③ |
| WEBAPP_URL | デプロイしたURL | ⑤ |
| LINE_TOKENS / LINE_GROUP_ID / SITE_URL | LINE通知 | LINEの設定（あとで） |
