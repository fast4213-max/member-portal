# 組合員台帳ポータル

組合員が自分の台帳（氏名・住所・家族・共済など）を**新規登録・変更申請**し、役員が**承認・閲覧・管理**する Web アプリです。
紙の組合員台帳と同じ並び・同じ見た目で入力・表示・印刷（A4）できます。スマホ・PC 両対応。

> ⚠ このリポジトリは**公開**です。ここにあるのは「プログラム」だけで、名簿データ・パスワード・組織名などは一切含みません。
> 取り扱いのルールは [SECURITY.md](SECURITY.md) を必ず読んでください。

---

## 1. しくみ

```
[スマホ／PCのブラウザ]
      │ 画面を開く（GitHub Pages：このリポジトリの docs/）
      ▼
[画面（HTML と JavaScript）]  ……  名簿データもパスワードも持たない
      │ 送信（ログイン・申請・一覧など）
      ▼
[Google Apps Script（GAS）]  ……  パスワード確認・権限チェック・入力チェックはすべてここ
      │
      ├─▶ [Google スプレッドシート]  ……  台帳の本体（共有は「制限付き」のまま）
      ├─▶ 毎日のバックアップ（Google ドライブ・30日分）
      └─▶ （後日）LINE に「承認待ちが N 件」とだけ通知
```

| 置き場所 | 中身 |
|---|---|
| GitHub（このリポジトリ） | プログラムと説明書だけ |
| GitHub Pages | 画面（`https://<GitHubのユーザー名>.github.io/member-portal/`） |
| Google スプレッドシート | 台帳のデータ（管理者の Google アカウントだけが開ける） |
| GAS のスクリプトプロパティ | パスワード（暗号化した値）・組織名・各種ID |

## 2. 使い方の流れ

### 組合員
1. 共通パスワードでログイン
2. **新規登録**：社員番号＋生年月日を入れると登録済みか自動で確認 → 未登録なら残りを入力
   **登録内容の更新**：社員番号＋生年月日で本人確認 → いまの内容を直す
3. 確認画面（紙の台帳と同じ形）で見直して **申請** → 役員の承認で台帳に反映

### 役員
- 管理パスワードでログイン
- **台帳一覧**：あ〜わ行・氏名・フリガナ・社員番号で検索。氏名を押すと台帳表示（印刷・編集・ゴミ箱・以前の版に戻す）
- **承認待ち**：変更前／変更後を見比べて承認・却下（却下は理由必須）
- **行動ログ**：だれが・いつ・何をしたか（住所などの値は記録しない）
- **ゴミ箱**：削除した台帳の復元・完全削除

### 申請のルール
- 組合員は台帳を直接変えられません。必ず「申請 → 役員が承認」を通ります
- 申請は何回出してもよく、**承認待ちとして残るのは1人につき最新の1件だけ**（前の申請は「置き換え済み」になる）
- 承認待ちの申請は、本人がいつでも取り消せます
- 申請のあとで台帳が変わっていた場合、承認はいったん止まり、役員が最新の内容と見比べてから承認し直します
- 1人あたり1日20回まで申請できます

## 3. 最初の構築

1. **GAS とスプレッドシート**：[gas/SETUP.md](gas/SETUP.md) の手順どおり（30分ほど）
2. **画面の接続先**：`docs/assets/api.js` の `GAS_URL` を、デプロイしたウェブアプリの URL（`…/exec`）にする
3. **GitHub Pages**：リポジトリの［Settings］→［Pages］→ Source「Deploy from a branch」、Branch「main」「/docs」→［Save］

## 4. スクリプトプロパティ（キー名だけ。値はここに書かない）

GAS の ⚙（プロジェクトの設定）→「スクリプト プロパティ」に入っています。ほとんどはスプレッドシートの［台帳アプリ］メニューから設定します。

| キー | 中身 | 設定のしかた |
|---|---|---|
| `SPREADSHEET_ID` | 台帳のスプレッドシート | ① 初期設定で自動 |
| `PASS_SALT` | 暗号化用のランダム文字列（変えるとパスワードの再設定が必要） | ① 初期設定で自動 |
| `BACKUP_FOLDER_ID` | バックアップ先フォルダ | ① 初期設定で自動 |
| `TOKEN_EPOCH` | ログインの世代番号（「全員をログアウト」で増える） | 自動 |
| `MEMBER_PASS_HASH` | 共通パスワード（暗号化済み） | ② 共通パスワードを設定 |
| `ADMIN_PASS_HASH` | 管理パスワード（暗号化済み） | ③ 管理パスワードを設定 |
| `ORG_TITLE` / `ORG_HONBU` / `ORG_BRANCH` / `ORG_BUNKAI` | 台帳の見出し・地方本部・支部・分会 | 組織名（台帳の見出し）を設定 |
| `WEBAPP_URL` | デプロイした URL（接続テスト用） | ⑤ Web接続テスト |
| `LINE_TOKENS` / `LINE_GROUP_ID` / `SITE_URL` | LINE 通知（後日） | LINEの設定 |

## 5. プログラムを直したとき

- **画面（`docs/`）**：main に push すると、1〜2分で GitHub Pages に反映されます
- **GAS（`gas/`）**：
  1. Apps Script で、変わったファイルの中身を貼り直して 💾 保存
  2. ［デプロイ］→［**デプロイを管理**］→ ✏ →「バージョン」を［**新バージョン**］→［デプロイ］
     （［新しいデプロイ］を選ぶと URL が変わり、画面からつながらなくなります）
  3. スプレッドシートの［台帳アプリ］→［④ 動作テスト］が全部 ✅、［⑤ Web接続テスト］でバージョンを確認
- **シートの列（`gas/schema.gs` の `SHEETS`）を変える修正**は、既存データの移し替えが必要です。列を変えない修正なら、データがずれることはありません

## 6. データの保管と復元

| 項目 | 内容 |
|---|---|
| 毎日のバックアップ | 毎日3時ごろ、スプレッドシートを丸ごとコピーして「組合員台帳_バックアップ」フォルダへ。**30日分**を残し、古いものは自動でゴミ箱へ |
| 手動バックアップ | ［台帳アプリ］→［今すぐバックアップ］ |
| ゴミ箱 | 削除した台帳は家族情報ごと残り、いつでも復元できる。**完全削除は削除から90日たってから**、管理パスワードの再入力が必要で、実行前に自動バックアップ |
| 変更履歴 | 承認・編集・削除の前の内容を `members_history` に残す。台帳表示の「変更履歴」から以前の版に戻せる |

### バックアップから戻す手順（大きな事故のときだけ）
1. ［台帳アプリ］→［全員をログアウトさせる］で、しばらく使わないよう周知
2. 念のため［今すぐバックアップ］で、いまの状態も残す
3. Google ドライブの「組合員台帳_バックアップ」から、戻したい日のファイルを開く
4. 戻したいシート（例：`members`）で Ctrl+A → コピー
5. 本番のスプレッドシートの同じ名前のシートで A1 を選び、右クリック →［特殊貼り付け］→［値のみ貼り付け］
6. 本番側に、バックアップより下の行が残っていたら削除する
7. ［④ 動作テスト］で確認してから、利用を再開

1人分だけ元に戻したいときは、この手順ではなく台帳表示の「変更履歴」→［戻す］を使ってください。

## 7. LINE 通知（後日）

`gas/line.gs` にコードはありますが、**設定しない限り何もしません**（毎日の自動処理も「未設定なのでスキップ」と記録するだけ）。
使うことになったら設定手順を追加します。考え方だけメモしておきます。

- 送るのは「承認待ちの申請が N 件あります」だけ（氏名などは書かない）。新しい承認待ちが増えた日だけ、1日1回
- 受信（Webhook）は使わず、送信（push）だけ
- 無料枠：グループへの送信は**人数分**数えられます（5人グループなら1回で5通。無料の月200通なら1つのBotで月40回まで）。最大5つの Bot を順番に使い、残りが足りる Bot で送ります

## 8. 限界（知っておいてほしいこと）

- GAS では相手の IP アドレスを取得できません。いたずら・総当たりの抑止は **承認制・申請の置き換え・回数制限・ロック・行動ログ** で行っています
- 共通パスワードは全員共通のため、5回続けて間違えると**全員が**15分ログインできなくなります（ロックは役員用と別）
- ログインの有効時間は6時間です（GAS の仕組み上の上限）。30分なにも操作しないと自動でログアウトします
- 申請は全体で1時間200回までです（いたずらの大量申請対策）。超えると1時間ほど受付を止めます

- [ ] 共通パスワード・管理パスワードを**変更**して、新しい担当者だけが管理パスワードを知る状態にする
- [ ] スプレッドシートの共有が「制限付き」のままか確認（「リンクを知っている全員」になっていないか）
